# 烬冠竞技场 (Embercrown Arena)

低多边形卡通风格的 3D 西式奇幻竞技场 ARPG。基于 **Three.js + Node.js (WebSocket)** 构建，使用 **Claude Fable 5.2 + Gemini Argon** 联合开发。

## 核心玩法

- **单人闯关**：无尽波次挑战，每 5 波登场强力首领（碎岩食人魔 / 枯冠巫妖 / 烬甲领主），波次间隙三选一祝福强化。
- **8 人联机混战**：30Hz 权威服务器结算，支持快速匹配、创建房间（自定义 Bot 数量与简单/普通/困难难度）、房间列表与 4 位房间号加入。
- **三大职业**：
  - **铁誓骑士**（近战 · 怒气）：高护甲减伤，盾牌猛击击晕、旋风斩吸血、目标锁定冲锋、天降神剑。
  - **翠林游侠**（远程 · 能量）：穿透利箭、扇形齐射减速、箭雨、翻滚无敌解减速、万箭风暴。
  - **余烬法师**（法术 · 法力）：爆炸火球、冰霜新星冻结、陨石术、闪现解控、炼狱火海。
- **全端适配**：支持 PC 键鼠、iOS/Android 横屏全屏虚拟摇杆与扇形技能轮盘，以及 **2880×1260 (3K 16:7)** 车机超宽屏原生渲染。

## 快速启动

```bash
npm install
npm start
```

启动后访问 `http://localhost:3000`（局域网玩家可通过控制台打印的局域网地址加入）。

> **安全提示**：公网部署时请务必通过环境变量 `DEMO_PASS` 设置独立访问口令，避免使用默认测试口令。

### 环境变量

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `PORT` | `3000` | HTTP 与 WebSocket 服务端口 |
| `DEMO_PASS` | `changeme` | 游戏入口与联机大厅访问口令（**公网部署请修改**） |
| `ADMIN_PORT` | `3001` | 管理统计端口（`0` 为关闭） |
| `ADMIN_TOKEN` | 空（未配置则拒绝访问） | 管理统计接口专用鉴权令牌（支持 `x-admin-token`、`Bearer` 或 `?token=`） |
| `BOT_FILL` | `4` | 默认房间补位人数（`0` 关闭 Bot） |
| `KILL_TARGET` | `15` | 联机模式获胜所需击杀数 |
| `ROUND_TIME` | `240` | 每局时长（秒） |

## 操作说明

- **PC 端**：`WASD` 移动 · 右键拖动转向 · `1–5` 技能/位移 · `空格` 跳跃 · `Tab` / 点击切换目标 · `C` 个人属性 · `O` 联机排行榜 · `Esc` 暂停/取消
- **移动端 / 触控屏**：左半屏虚拟摇杆移动 · 右半屏滑动视角 · 点击敌人锁定目标 · 右下角扇形技能轮盘出招

## 项目结构

- `server.js`：HTTP 静态服务 + `/ws` 权威联机服务器（30 tick/s 物理、技能、AI Bot 与状态同步）+ SQLite 遥测日志
- `public/index.html`：Three.js 3D 渲染、程序化低多边形建模、Web Audio 合成音效、单人逻辑与联机预测插值客户端
- `public/vendor/three.min.js`：Three.js r128（MIT）
