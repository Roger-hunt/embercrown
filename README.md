# 烬冠竞技场 (v1.5.0patch2)

低多边形卡通风格的西式奇幻竞技场游戏。两种玩法：

- **单人闯关**：无尽波次（含「深潜者斥候」等低多边形怪物），每 5 波一个首领，波次之间选一项祝福。
- **联机对战（支持「标准竞技」与「娱乐乱斗」）**：每个房间最多 8 人的自由混战，先拿到 15 次击杀获胜；时间到则击杀最多者获胜，随后自动开下一局。
  - **娱乐乱斗**：随机刷新神秘盲盒（随机增益 / 整蛊减益）、40 秒限时能力（💀 死亡之握抓人破风筝、🪃 随动回旋镖、⭐ 无敌星、🍄 狂暴巨人、⚡ 闪电超载）与可投掷/触发道具（💣 定时炸弹、🍌 香蕉皮陷阱、🚀 火箭靴）。拾取后临时替换 `4` 号大招位，按 `G` 或点击槽位角标 `×` 可丢弃。

## 运行

```bash
npm install
npm start              # http://localhost:3000，同一局域网的人用启动时打印的局域网地址进入
```

| 环境变量 | 默认 | 作用 |
| --- | --- | --- |
| `PORT` | 3000 | 端口 |
| `DEMO_PASS` | 随机 | 访问口令。`DEMO_AUTH=1` 时启用口令校验，不设置时随机生成并打印在控制台 |
| `TRUST_PROXY` | 关 | 在反向代理后面时设置。填代理的 IP（多个用逗号分隔）只信任它们发来的 `X-Forwarded-For`；填 `1` 信任任何来源 |
| `ADMIN_TOKEN` | 无 | 设置后才启动管理端口，用 `X-Admin-Token` 或 `Authorization: Bearer` 请求头访问 |
| `ADMIN_PORT` / `ADMIN_HOST` | 3001 / 127.0.0.1 | 管理端口和监听地址 |
| `BOT_FILL` | 4 | 真人不足时用电脑对手把房间补到几人，`0` 关闭 |
| `KILL_TARGET` | 15 | 获胜所需击杀数 |
| `ROUND_TIME` | 240 | 每局秒数 |
| `DEBUG` | 关 | `1` 时把调试日志也打印到控制台，不影响玩法 |
| `DEV_START_WAVE` | 0 | 调试用：单人模式从第几波开始 |
| `DB_PATH` / `SEC_LOG` | `data/` 下 | 遥测数据库和安全日志（fail2ban 格式）的位置 |

进入页面经过双深潜者把守的竞技场大门登录界面与资源预加载后进入主菜单。联机大厅支持选择「标准竞技 / 娱乐乱斗」快速匹配、浏览活跃房间列表、创建房间（支持设置 Bot 数量、模式与 6 位数字密码），或输入 4 位房间号加入。

## 操作

WASD 移动（`A`/`D` 左右平移）· 右键拖动转向 · 1–5 技能（4 是大招或娱乐模式临时能力/道具：常规大招先选范围再确认，娱乐能力/投掷道具按 4 直接朝准星施放）· G 丢弃娱乐道具 · 空格跳跃 · Tab 选目标 · 轻点 `1` 切换自动攻击（PC 默认开启，按住 `1` 为普通攻击，`F` 亦可）· C 属性面板 · O 战榜 · Esc 菜单。支持标准手柄。暂停菜单里可以关闭音效和观众（关闭观众能提高帧率）、切换「视角跟随」。手机上左半屏拖动移动，自动瞄准最近的敌人，右下角按钮出招。

## 结构

- `server.js`：静态文件 + WebSocket（`/ws`）。服务器权威，30 次/秒结算移动、命中、伤害、娱乐道具和击杀；客户端只上传输入。
- `public/index.html`：整个客户端（Three.js 低多边形渲染、登录门廊转场、单人逻辑、联机预测与插值）。
- `public/vendor/three.min.js`：Three.js r128，本地提供，离线局域网也能玩。
- `public/greta_yell.mp3`、`public/godlike.mp3`：首领语音和"超神"播报（后者由 flite 合成，可直接换成同名文件）。
- `GET /healthz`：返回当前房间数、在线人数与服务器负载状态。`POST /auth` 用口令换 24 小时令牌，`GET /rooms` 返回活跃房间列表（含难度与模式标记 `fun`）。
- `data/telemetry.db`：访问、负载和调试日志（SQLite），依赖 `better-sqlite3`。
- 遥测（单人明细 / P2P 房主摘要）自 `v1.5.0patch3` 起统一收在 Cloudflare D1，表结构见 `migrations/`；官服节点上只剩历史数据与访问日志。
- `tests/`：回归测试，`bash tests/run.sh` 一键运行（隔离实例，不碰线上），说明见 [tests/README.md](tests/README.md)。

## 最近更新 (v1.5.0patch2)

- **操作与视角**：`A`/`D` 改为默认左右平移（`Q`/`E` 备用，方向键仍负责转向）；PC 默认开启自动普攻，轻点 `1` 切换（按住 `1` 仍照常普攻）；暂停菜单新增「视角跟随」开关，**默认关闭**，开启后镜头才会自动转向当前目标；跳过波次等待的提示按当前操作方式显示（空格 / 手柄 `A` / 点击按钮）。
- **数据与隐私**：单人每局结束、联机每局结束各回传一包摘要——单人含职业、波次时长、每波击杀构成与受伤、首领 TTK、祝福组合、输入方式；联机含进房／离开、对局结算与逐次击杀，P2P 直连房由房主额外上报一份不含昵称、不含玩家 IP 的房间摘要。「关于 → 数据与隐私」逐条披露采集项、不采集项、用途与真实保留期（单发明细 180 天，访问与对局日志滚动保留最近 5 万条），并提供一键关闭上报的开关（关闭后单人明细与 P2P 摘要立刻停传；联机的进房／对局日志由服务端为保证房间运行与限流保留，不受开关控制）。单机离线版打包时整块剥离遥测，包内不含任何上报代码。
- **单人难度曲线**：怪物血量改为二次成长（第 30 波 16.2 倍），伤害同步上调；出怪按造价加权、同屏上限提到 26；祝福改为「数值下调 + 第 5 层起收益减半」，`铁石之躯` 改为百分比；首领血量独立成长。详见 `BALANCE-SOLO.md`。
- **平衡修正（据 133 波实测）**：`铁石之躯` 前 8 次仍是生命上限 +18%，之后每次改固定 +24（41 层从 885 倍生命 / 124,039 落到 1,318）；`嗜血獠牙` 保留每次击杀 +3，但新增每秒回血预算 = 最大生命的 2%。细节与回归测试见 `BALANCE-SOLO.md` §4.4.1。

### v1.5.0patch1

- **联机中立小鸡**：联机房间同步生成中立小鸡，支持鼠标点击或手柄锁定，骑士冲锋、挥砍及各类技能/飞弹均可命中并协助攒怒气。
- **移动端触控优化**：右下角核心大按钮调整为 2 号技能，普攻移至外圈并支持长按切换自动普攻（`AUTO`）；大招支持按下拖放瞄准与快速轻点保留瞄准；自动普攻仅在普攻射程内触发并自动朝向锁定目标。
- **界面与布局优化**：紧凑化移动端「模式与难度」选择弹窗，修复竖屏登录旋转提示层级并调整双深潜者构图，移除主菜单冗余语言按钮。
